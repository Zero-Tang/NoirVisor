# NoirVisor Drivers
This directory contains codes that NoirVisor may use to drive external hardware.

## ACPI
The Advanced Configuration and Power Interface (ACPI) is a powerful tool for NoirVisor to observe the system device configurations.

## HPET
The High-Precision Event Timer (HPET) is a commonly seen hardware in x86 platforms. NoirVisor may utilize this hardware for time-profiler.

## IOMMU
The I/O Memory Management Unit (IOMMU) is a crucial external hardware that virtualizes DMA requests and external interrupts.
